# pgzero_platform_game
Este projeto é um jogo de plataforma 2D desenvolvido em Python, utilizando a biblioteca Pygame Zero. O objetivo principal foi criar um jogo simples, organizado e fácil de entender, pensado como ferramenta de aprendizagem para crianças iniciantes em programação.  O código foi estruturado de forma clara, com separação de responsabilidades e uso de classes, facilitando a leitura e a manutenção

pip install pgzero
pgzrun main.py
